# Retail Sales Analysis & Prediction

## Project Overview
This project focuses on analyzing retail sales data and predicting sales using Python, data visualization, and machine learning.

The goal is to understand sales trends, profit performance, regional distribution, and the factors that influence sales.

## Objectives
- Analyze retail sales and profit.
- Explore regional and category-wise performance.
- Understand monthly sales trends.
- Analyze shipping performance.
- Build a machine learning model to predict sales.
- Compare original and improved Random Forest models.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Results

| Metric | Original Model | Improved Model |
|---|---:|---:|
| MAE | 215.75 | 203.35 |
| RMSE | 640.24 | 627.11 |
| R² Score | 0.2148 | 0.2467 |

The improved Random Forest model performed slightly better than the original model.

## Key Findings
- Quantity was the most important feature in the model.
- Order month and order year also contributed to predictions.
- Technology showed strong profit performance.
- The improved model achieved lower MAE and RMSE.
